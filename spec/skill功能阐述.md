# Skill功能阐述
1. 给定代码仓库，使用skill的智能体需要先分析项目结构，确保理解：项目仓库解决的需求和目标、项目系统架构、项目实际可用功能、项目的代码结构、项目的核心算法、项目的测试方案、项目的测试结果，全部信息都应该完整依据用户给定的项目，项目源代码是唯一的事实依据，智能体需要在tmp目录下，存储理解到的信息文档，作为唯一事实依据，便于后续写报告了。
2. 这个skill还需要让agent理解课程设计报告的规范：根据报告模板，报告主体分为
   1. 选题背景：说明本项目应解决的主要问题及应达到的技术要求，简述本设计的指导思想。
   2. 方案论证(设计理念)：说明设计原理（理念）并进行方案选择，阐明为什么要选择这个设计方案以及所采用方案的特点。包括：
      - 需求分析思路说明：需要有对系统要实现的功能和目标总的概括、报告中必须有规范的用例图、系统功能结构图说明系统功能、用户活动图分析用户操作流程、时序图说明系统关键功能执行时的时间序列、需要有对系统边界的约束和规范，系统的安全性、数据的完整性、应用的运行环境及其性能等要求。
      - 系统设计思路说明：报告中必须阐述为了实现需求，系统的架构是如何设计的，系统的技术栈是如何选择的，系统的顶层，一层，二层数据流是什么样的，系统的的包图说明系统的代码结构是什么样的，类图说明类和对象是如何设计的
       - 上述正文放到 "二、方案论证(设计理念)" 下方
   3. 过程论述：重点说明设计是如何实现的，要求层次分明、表达确切。每个图都必须有文字说明，图前说明为什么使用该图、图的主要作用；图后说明图中各成分的作用，和成分之间的交互或图所表达的流程。包括
     - 系统实现思路的说明：报告中必须阐述代码实现的思路是什么样的，结合算法流程图阐述清楚核心功能代码的实现思路和关键逻辑代码

   4. 结果分析：包括
     - 系统测试的思路说明：报告中必须阐述项目测试的方法以及目的，并附上测试结果，和结果说明。
3. 这个skill还需要让agent学会撰写最终的课程设计报告书：实验报告必须图文并茂，skill需要教会agent使用PlantUML绘制标准的UML图，使用D2绘制标准的系统架构图等，skill需要让agent自己完成系统测试，并使用相关工具进行截图放到 `image` 目录便于写最终报告
4. 这个skill需求让agent学会需要撰写的正文模板内容的在docx中的排版格式，具体的排版格式在 [课程设计报告书模板.md](../课程设计报告书模板.md课程设计报告书.md) 中有详细的标注
5. 使用该skill后agent可以写出符合要求的最终报告，md格式和docx格式。
