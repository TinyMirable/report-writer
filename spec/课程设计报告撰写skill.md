# 课程设计报告撰写skill

这个项目的目标是：在仓库的根目录的`my_skill`目录下创建一个skill，交付一个可用的skill：可以给现有智能体直接使用，能够让智能体根据项目代码生成格式正确，内容规范的课程设计报告。

## 事实源

本文档只定义交付范围和文档入口。若本文档与事实源冲突，以对应事实源为准。

| 内容                  | 事实源                    |
| --------------------- | ------------------------- |
| skill功能说明         | `spec/skill功能阐述.md` |
| Diagram Layout Policy | `spec/skill功能阐述.md` |

## 必须交付内容

一个完整的skill

## 验收标准

1. codex等智能助手可以直接使用该skill
2. 使用该skill的智能助手可以正确解析项目，理解项目的目标和功能，项目做需求分析的思路，项目做系统设计的思路，项目做测试的思路
3. 使用该skill的智能助手可以完全理解最终要交付的报告是什么样的，报告使用的模板，模板中每个部分需要写什么内容
4. 使用该skill的智能体知道项目需要哪些图，以及图如何获取，并按部就班的绘图，检验图和写报告
5. 使用该skill的智能体能够交付完整的md和docx文件，做到图文并茂，格式正确，做到上面提到的所有要求
6. skill限制智能体在撰写报告的时候
   - 需求分析中必须要有用例图，明确的系统约束和规范
   - 系统设计分析思路中必须有系统架构图，系统的顶层数据流图，系统的一层，二层数据流图，包图，其他图可选
   - 系统实现思路的说明中：必须有核心代码的流程图，实现思路说明和关键逻辑源代码附上，源代码格式：使用等宽字体（Consolas/Cascadia Code）10.5pt、浅灰或深灰背景、保留缩进
   - 系统测试的思路说明中，如果项目包含前端，必须附上所有测试结果截图和说明，如果是无前端项目，必须附上测试运行的关键结果表和说明
